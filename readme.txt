AgendaPro adiciona agendamento online para clinicas e consultorios com painel administrativo, shortcode publico e webhooks.

== Description ==

Use o shortcode [agendapro_booking] para exibir o formulario de agendamento.
Use o shortcode [agendapro_my_appointments] para permitir que pacientes consultem seus horarios pelo WhatsApp.

== Installation ==

1. Envie a pasta do plugin para wp-content/plugins/agendapro.
2. Ative o plugin no painel do WordPress.
3. Cadastre servicos, profissionais e horarios em AgendaPro.
4. Insira o shortcode em uma pagina.
